# WanderLux Travel — ICT502 Assessment 2

Six-page static HTML/CSS/JavaScript demonstration website.

## Run locally
Open `index.html` in a browser or use VS Code Live Server. Internet access is needed for externally hosted Unsplash photographs and Google Fonts.

## Test
- Navigate all six pages; resize to mobile and tablet widths.
- Calculate Bali, 2 travellers, 5 days, Standard: AUD 1,990 (110+65)*5*2+120*2.
- Test invalid traveller/day values and required fields.
- Test appointment/contact forms with invalid email and valid inputs.
- Test keyboard navigation and reduced-motion preference.

## Publish
GitHub Pages: create a public repository, upload all files preserving the assets folder, go to Settings > Pages, choose Deploy from branch > main / root, save and wait for the site URL. Paste the verified URL into the report.

## Important limits
- Email forms use `mailto:` and require a configured mail client and manual send. They do not independently transmit or store messages.
- `hello@wanderlux.example` is a reserved placeholder, not a real recipient. Replace with an actual monitored inbox before public use.
- Destination rates are invented illustrative figures, not real quotations.
- Agency location, staff and services are demonstration content.
- Images and fonts load from external third-party providers; consider locally hosted licensed assets for production.
